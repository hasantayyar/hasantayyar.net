# The Hidden Score

An interactive audiovisual artwork exploring Rule 30, built with plain HTML, CSS and JavaScript. No installation or external dependencies.

I recently watched this amazing video about rule 30 showing the beauty of this. https://www.youtube.com/watch?v=HcGjCcLEgN4

After seeing it I wanted to iterate some simulations. 

There is a prize for rule 30 https://www.rule30prize.org/ and it makes this more exciting.

## Explore

- **Tapestry:** watch and hear the automaton.
- **Hidden order:** reveal repeating right-edge diagonals.
- **One-bit echo:** change one cell and compare the resulting futures.

Click **Listen** to enable sound. **Space** pauses, **1–3** switch views, **M** mutes, and **F** opens fullscreen.

The wave is a visual effect; cell values follow `L XOR (C OR R)`. Finite observations do not prove randomness.

Inspired by [Eric Rowland’s research](https://ericrowland.github.io/papers/Local_nested_structure_in_rule_30.pdf).
