An interactive audio visual artwork exploring [Rule 30](https://web.archive.org/web/20260909143457/https://mathworld.wolfram.com/Rule30.html), built with plain HTML, CSS and JavaScript. 

I recently watched [this amazing video](https://www.youtube.com/watch?v=HcGjCcLEgN4) about rule 30 showing the beauty of this from Eric Rowland: [https://www.youtube.com/watch?v=HcGjCcLEgN4](https://www.youtube.com/watch?v=HcGjCcLEgN4)
There is a prize for rule 30 https://www.rule30prize.org/ and it makes this more exciting.

After seeing it I wanted to iterate some simulations using audio and visual elements.

**Explore the project: [https://hasantayyar.net/assets/rule30/](https://hasantayyar.net/assets/rule30/)**

The project uses Web Audio API and there are modes:

- **Tapestry:** watch and hear the automaton.
- **Hidden order:** reveal repeating right-edge diagonals.
- **One-bit echo:** change one cell and compare the resulting futures.

Click **Listen** to enable sound. **Space** pauses, **1–3** switch views, **M** mutes, and **F** opens fullscreen.

The wave is a visual effect; cell values follow `L XOR (C OR R)`. Finite observations do not prove randomness.

__Inspired by [Eric Rowland’s research](https://ericrowland.github.io/papers/Local_nested_structure_in_rule_30.pdf).__
